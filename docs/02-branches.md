# Branches



## O que é uma branch?



Uma branch é uma referência para uma linha de desenvolvimento dentro de um repositório Git.



Ela permite desenvolver ou testar alterações de forma isolada, sem modificar diretamente a versão principal do projeto.



A branch `main` normalmente representa uma versão estável do projeto.



## Criando uma branch



Para criar uma branch e mudar para ela, podemos usar:



```bash

git switch -c nome-da-branch
