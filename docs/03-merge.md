# Merge



## O que é merge?



Merge é o processo utilizado pelo Git para integrar as alterações de uma branch em outra.



Por exemplo, depois de terminar uma alteração em uma branch de documentação, podemos integrar esse trabalho à branch `main`.



## Exemplo



Suponha que existam duas branches:



- `main`

- `docs/estrutura-guia`



Depois de finalizar o trabalho em `docs/estrutura-guia`, podemos mudar para a `main` e executar:



```bash

git switch main
