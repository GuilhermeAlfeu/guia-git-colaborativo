\# Pull Request



\## O que é um Pull Request?



Pull Request (PR) é uma solicitação para integrar as alterações de uma branch em outra.



No GitHub, um Pull Request permite apresentar as alterações realizadas, revisar o código ou conteúdo e discutir possíveis melhorias antes da integração.



\## Fluxo básico



Um fluxo comum para utilizar um Pull Request é:



1\. Criar uma branch.

2\. Fazer as alterações necessárias.

3\. Registrar as alterações em commits.

4\. Publicar a branch no GitHub.

5\. Abrir um Pull Request.

6\. Revisar as alterações.

7\. Integrar a branch ao projeto.
